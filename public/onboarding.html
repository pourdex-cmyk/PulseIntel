Getting started guide
Four steps to a fully operational intelligence workspace
In progress
1
Connect your first integration
Navigate to Settings → Integrations. Start with your most-used email platform (Outlook or Gmail). The setup wizard walks you through OAuth authorization — no developer knowledge required.
Settings → Integrations → Connect
2
Set your AI communication profile
Tell Pulse how you communicate. Set your tone (professional, direct, formal, friendly), draft length preference, and add a signoff. This trains AI drafts to sound exactly like you — not like a bot.
Settings → Profile → Communication Style
3
Generate your first daily briefing
Once messages are flowing in, open the AI menu and request your Daily Intelligence Report. You'll get a plain-English executive summary of everything that matters — across every connected platform.
Inbox → AI Menu → Daily Report
4
Optionally add your own Claude API key
For maximum data sovereignty — where your message content never leaves your infrastructure — add your own Anthropic API key. Visit console.anthropic.com to generate one.
Settings → AI Configuration → API Key
